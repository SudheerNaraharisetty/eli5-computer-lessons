# ELI5 Computer Lessons

Beginner courses with big pictures, few words, and interactive quizzes. Open a topic's `index.html` in a browser.

## Topics

- [Learn GitHub](learn-github/): Git and GitHub from zero to expert, all from the terminal.
- [Learn Python](learn-python/): Python from zero to master, told in your own kitchen, with code you run in the page and exercises you open in VS Code.
- [Learn Principles](learn-principles/): software engineering principles, the 25 most used first, each with a short video.
